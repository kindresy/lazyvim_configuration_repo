# rime.vim for LazyVim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a Lua-enabled librime, Rime Ice, and `TSalmon3/rime.vim` so local LazyVim can input Simplified Chinese with the default `;;` toggle.

**Architecture:** Build pinned librime `1.17.0` with librime-lua into `/usr/local`, install a pinned local snapshot of the Vim frontend for Lazy to load, and compile its native backend. Keep all Rime configuration and user-dictionary state in `~/.local/share/rime-nvim` so it cannot conflict with a system input method.

**Tech Stack:** Ubuntu 22.04 apt packages, CMake/Make/C++17, glog 0.7.1, librime 1.17.0, librime-lua, Rime Ice 2026.06.30, Neovim 0.12, LazyVim/lazy.nvim, Vimscript plugin configured from Lua.

## Global Constraints

- Preserve every pre-existing uncommitted change in `/home/luyuan/.config/nvim`.
- Install source-built libraries only under `/usr/local`; do not overwrite Ubuntu-managed files under `/usr`.
- Pin librime to stable release `1.17.0`.
- Use `/home/luyuan/.local/share/rime-nvim` as the dedicated Rime user data directory.
- Keep the default full-Pinyin schema and `;;` toggle mapping.
- Write the backend log to `/home/luyuan/.local/state/nvim/rime.log`.

### Task 3: Add and install the LazyVim plugin

**Interfaces:**

- Produces: Lazy plugin spec and the `rime-query` backend used by `:IMStart`.

- [ ] **Step 1: Run a failing configuration probe**

Run:

```bash

```

Expected: FAIL because the plugin spec does not exist yet.

- [ ] **Step 2: Create the minimal plugin spec**

Create `/home/luyuan/.config/nvim/lua/plugins/rime.lua` with:

```lua
local plugin_dir = vim.fn.stdpath("data") .. "/local/rime.vim"

return {
  {
    dir = plugin_dir,
    name = "rime.vim",
    url = "https://github.com/TSalmon3/rime.vim",
    build = "CXX=clang++ cmake -S cpp -B cpp/build && cmake --build cpp/build -j2",
    init = function()
      local backend_dir = plugin_dir .. "/cpp/build"
      vim.env.PATH = backend_dir .. ":" .. vim.env.PATH
      vim.g.im_rime_bin = backend_dir .. "/rime-query"
      vim.g.im_user_data_dir = vim.fn.expand("~/.local/share/rime-nvim")
      vim.g.im_shared_data_dir = vim.fn.expand("~/.local/share/rime-nvim")
      vim.g.im_log_file = vim.fn.expand("~/.local/state/nvim/rime.log")
      vim.g.im_toggle_key = ";;"
    end,
  },
}
```
